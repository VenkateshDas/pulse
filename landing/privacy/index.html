Website privacy

Updated 1 November 2026. This website does not inspect your Mac’s files or system readings.

Website measurement

Basic website analytics start automatically on the homepage, guide index and published guide. PostHog processes page views, broad referral sources and selected button clicks. We send only approved page paths and fixed interaction labels, not typed text, email addresses, file names, URL queries or recordings.

Each page load gets a fresh random identifier held only in memory. No analytics cookie, saved visitor identifier or fingerprint is used. We do not identify you or track returning visits across page loads. IP storage and location enrichment are disabled in our PostHog configuration; your browser still connects to PostHog’s EU ingestion service, which necessarily receives network connection information to handle the request. See PostHog’s privacy policy.

We respect Global Privacy Control and Do Not Track signals, as well as a previous analytics opt-out. Your preference, if saved, is stored in this browser separately from measurement. Turning analytics off stops future collection here; it does not delete events already received. This privacy page itself sends no measurement events.

Your preference is checked when this page loads.

Early-access signup

Our signup form is hosted by MailerLite. When you subscribe, MailerLite processes your email address and technical signup records, including IP address and confirmation activity, to manage the list and record your signup consent. We use this information for early-access invitations and occasional Pulse updates. This is separate from website measurement.

Unsubscribe using the link in our emails, or contact getpulseapp01@gmail.com to request removal. See MailerLite’s privacy policy.
